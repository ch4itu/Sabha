# Publication status

This directory is the documentation-first public review candidate for Sabha Matchchain v0.1.0-rc1 (SMC3).

The normative protocol specification, security boundaries, whitepaper and release metadata are included for review. The executable implementation and full conformance/adversarial suite remain in the signed r23.7.2 release bundle until the r24 single-canonical-core cutover proves byte-equivalence between the public source and the Sabha Ludo embedded core.

This is deliberate: no duplicate implementation is being declared canonical before the r24 migration gate closes.

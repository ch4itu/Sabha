⚠ Keep this tab in the foreground with the screen on. Local models run in your phone's GPU. If you switch apps, lock the screen, or let it sleep, the browser unloads the model and local agents pause until you reload it. For unattended or background running, use a cloud provider instead — it has no GPU context to lose.
🔗 Use custom model (Arweave / IPFS / your own host)
Paste an IPFS CID, an Arweave transaction ID, or a full folder URL. The app reads mlc-chat-config.json from that location and auto-detects everything else (WASM lib, model identifier).
Examples: bafybeifyjrgdvccgt7yvyncxaimdvobqbnnogvixtwukipxq6kgvukxd7m (IPFS) · arweave.net/<TX> · https://your-gateway/ipfs/<CID>/
